ECART - Online Shopping Platform 🛒
ECART is a robust and user-friendly online shopping platform built using Java, Spring Boot, and MySQL. It provides a seamless shopping experience for users with efficient product browsing, cart management, and secure payment processing.

🔹 Features
✅ User Authentication & Authorization (JWT-based security)
✅ Product Catalog with categories & search functionality
✅ Shopping Cart & Wishlist management
✅ Order Processing with real-time updates
✅ Secure Payments Integration
✅ Admin Dashboard for product & order management
✅ RESTful APIs for smooth communication

🔹 Tech Stack
Backend: Java, Spring Boot, Hibernate, MySQL

Frontend: HTML, CSS, JavaScript (or React if applicable)

Security: Spring Security, JWT

Database: MySQL
